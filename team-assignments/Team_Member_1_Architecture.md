# Team Member 1: Project Architect & DevOps

## Role Overview
You are responsible for the foundational setup of the project. You manage the Next.js configuration, Tailwind CSS setup, global styles, root layout, and repository health.

## Core Tasks
1. **Global Styling**: Manage `globals.css` with the custom Angaar Labs CSS variables (colors, fonts, custom animations like `animate-pulse`, `animate-float`).
2. **App Layout**: Manage `src/app/layout.tsx` including the custom fonts (Inter & Space Grotesk) and global metadata.
3. **Tooling**: Ensure `package.json` has all necessary dependencies (Framer Motion, GSAP, Tailwind).

## Key Files to Commit
- `package.json`
- `src/app/layout.tsx`
- `src/app/globals.css`
- `tailwind.config.ts` (or `postcss.config.mjs`)
