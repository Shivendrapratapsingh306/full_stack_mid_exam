# Team Member 5: Full-Stack & Data Engineer

## Role Overview
You are responsible for the data layer, secondary pages, and complex interactions (forms, filtering). You handle how data is fetched and displayed.

## Core Tasks
1. **Data Mocking/APIs**: Maintain the `projectsData.ts` file and the `lib/projects.ts` fetcher functions to simulate database retrieval.
2. **Projects Page**: Build and manage `src/app/work/page.tsx`, implementing the scroll-controlled background video and the client-side filtering logic.
3. **Contact Page**: Build `src/app/contact/page.tsx` including a robust contact form with state management and input validation.
4. **Project Cards**: Manage the logic inside `src/components/work/ProjectCard.tsx`.
