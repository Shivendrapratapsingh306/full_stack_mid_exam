# Team Member 2: UI/UX Component Engineer

## Role Overview
You are responsible for the project's Design System. You build the reusable "dumb" UI components that the rest of the team will use to build their sections. 

## Core Tasks
1. **Base Components**: Build and refine reusable UI elements like buttons, cards, and badges.
2. **Navigation**: Manage the main `Navbar.tsx` and `Footer.tsx`.
3. **Utility Components**: Manage the `Container.tsx` and `SectionHeading.tsx`.
4. **Widgets**: Manage the global floating `ContactWidget.tsx`.

## Key Files to Commit
- `src/components/ui/Button.tsx`
- `src/components/ui/Card.tsx`
- `src/components/ui/Badge.tsx`
- `src/components/ui/Container.tsx`
- `src/components/ui/SectionHeading.tsx`
- `src/components/ui/ContactWidget.tsx`
- `src/components/layout/Navbar.tsx`
- `src/components/layout/Footer.tsx`
